# Security policy

## Supported versions

Security fixes are provided for the latest released minor version.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's **Report a vulnerability** private advisory flow in the
Security tab. Include affected versions, impact, reproduction steps, and any suggested
mitigation. You should receive an acknowledgement within seven days. A coordinated disclosure
date will be agreed after impact and remediation are understood.

Never include production credentials, personal data, or destructive payloads in a report.
